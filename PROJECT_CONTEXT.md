## О чём проект

**«Цифровая исповедь»** — экспериментальный документальный фильм 20–30 минут,
производство студии **1147 Продакшнс**. Метод: реальные исповеди людей,
озвученные через ИИ-аватаров. Премьера — осень 2026.

Структура фильма: 3 акта (рождение → взросление → старость и смерть).
Целевые фестивали: «Послание к человеку» (СПб), «Докер» (Москва), Beat Film.

**Сайт.** Одностраничный лендинг для набора героев — анкета через Google Form,
описание проекта, трейлер, туториал по съёмке, темы для исповеди, секция
согласия со скачиваемым PDF, команда.

## Структура папок


## Стилистические решения (важно соблюдать)

- **Шрифты**: `PT Mono` (Google Fonts) — основной, моноширинный, кириллический.
  `PT Serif Italic` — **только для цитат и лид-абзацев**, нигде больше курсива нет.
- **Палитра** (CSS-переменные в `:root`):
  - `--bg: #f4f1ec` — тёплый off-white фон
  - `--ink: #0a0a0a` — основной текст
  - `--accent: #c1272d` — красный (poppy red), **единственный цвет** в системе
  - `--mute: #6a665e`, `--line: #c8c2b8` — серые градации
- **Жирный текст**: PT Mono доступен только в weight 400. Жирность даётся через
  `-webkit-text-stroke` — обводка тем же цветом. Не менять на `font-weight: bold`.
- **Эффекты**: тонкий film grain (SVG noise) и сканлайны (3px repeating-gradient)
  поверх всего через `body::before` и `body::after`. Не отключать без причины.
- **Тайм-коды и REC-индикаторы**: имитация камеры наблюдения — везде один стиль
  (`.cam-overlay`, `.cam-tc`, `.cam-rec`, `.cam-cam`).
- **Hover-анимации**: на картинках убирается grayscale + scale 1.04–1.06. CTA-кнопки
  заливаются акцентом с translateX. Не плодить новые эффекты.

## Хранилище и шрифты

- **Шрифты** грузятся с Google Fonts через preconnect (PT Mono, PT Serif).
  Если перенесёте сайт на закрытый хостинг — скачайте файлы локально.
- **Картинки** — все в `images/`, относительные пути. Если деплой переместит
  файлы, нужно проверить пути.
- **Картинки оптимизированы** до 1600px / q82 JPEG. Если нужно ещё легче —
  можно конвертировать в WebP/AVIF, но это требует добавить `<picture>` теги.

## Деплой

Самый простой путь:
1. Запаковать папку `site/` в ZIP
2. **Netlify**: зайти на app.netlify.com → drag-and-drop ZIP
3. **Vercel**: `vercel deploy` из папки или drag-and-drop
4. **Tilda/Тильда**: загрузить картинки в проект, скопировать HTML в блок T123

После деплоя — поменять Vimeo Privacy на этот домен.

## Принципы экономии токенов при дальнейших правках

- Для **локальных правок** (изменить текст, цвет, ссылку) — используйте
  `str_replace` или прямо в редакторе. Это дешевле всего.
- Для **новых секций** — лучше показать ИИ структуру существующей секции
  как образец, попросить вставить новую таким же стилем через str_replace.
- **Не меняйте глобальные параметры посреди работы** — фон, шрифт, базовую
  палитру. Это каскадно ломает десятки мест.
- Если правок много — иногда дешевле перезаписать файл целиком, чем делать
  10 точечных правок. ИИ сам выберет.
